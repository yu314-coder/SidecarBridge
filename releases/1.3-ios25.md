## Experimental live MetalFX upscaling
- Developer-only toggle: Settings > Developer > Live 1080p → display upscaling.
- Reuses AVSampleBufferVideoRenderer's displayed decoded pixel buffer; no second H.264 decoder.
- Converts the decoded frame into a private Metal texture, runs MetalFX spatial scaling, and presents to a Metal view at the physical display size.
- Activates only when both output dimensions are larger than the received stream.
- Preserves the source aspect ratio and avoids reprocessing the same displayed pixel buffer.
- The existing AVSampleBufferDisplayLayer remains underneath for immediate fallback and Picture in Picture.
- In-flight GPU work keeps the last successful frame visible instead of hiding/flashing the overlay.
- Developer status and copied diagnostics report received/output resolution and live render time.
- Requires iOS 17.4 or later and supported physical MetalFX hardware.
