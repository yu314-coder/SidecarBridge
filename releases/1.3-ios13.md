## What changed

- Optional in-app VNC viewer/controller, without installing a Mac companion.
- Explicit hostname/IP, port, and separate VNC-password connection flow.
- Optional Keychain password saving after successful authentication and a frame.
- Touch, mouse/trackpad, click/drag/scroll, keyboard/modifier messages, and local
  pinch zoom through the existing input surface.
- Mac-local Command-V, without automatic iPad clipboard access.
- Bounded frame parsing, resize support, TCP keepalive, initial-frame timeout,
  and explicit fresh-screen reconnect after backgrounding.

See [setup and limitations](../MAC_SCREEN_SHARING.md). This is not native
Sidecar; standard VNC is unencrypted and intended here for trusted local networks.
A USB cable alone does not provide an IP connection. Physical iPad/Mac VNC
compatibility, input, and reconnection still need user testing.
