# SidecarBridge 1.4 — iOS/iPadOS (1), macOS (106)

Release preparation: 2026-09-22. iOS/iPadOS starts the 1.4 train at build
**1**. macOS continues its cross-version sequence at build **106**. Archive
export disables automatic version/build-number changes.

## Changes

- Optional developer-only live frame interpolation on supported physical
  iOS/iPadOS 26+ devices. Start with 1080p60 on a 120 Hz iPad; view generated
  output and submission-timing diagnostics in Settings > Developer.
- Preserve native high-resolution video when interpolation is unsupported;
  automatically fall back under load and pause generation during PiP.
- Configure the actual Picture in Picture background playback capability
  and session. A healthy PiP session no longer needs a complete video restart
  when returning to the app. The new Mac resume behavior is negotiated for
  compatibility with older companion versions.
- Closing PiP cancels automatic restart attempts. Background continuity
  depends on visible PiP and iPadOS scheduling; indefinite invisible execution
  is not promised.

See [implementation, testing instructions and App Review notes](../FRAME_INTERPOLATION_AND_BACKGROUND.md).
