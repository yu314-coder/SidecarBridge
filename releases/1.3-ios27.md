# SidecarBridge iOS/iPadOS 1.3 (27)

## Cursor fix

- The viewer now always renders the actual normalized Quartz cursor position acknowledged by the Mac after pointer input.
- Cursor visibility no longer depends only on ScreenCaptureKit embedding the cursor into compressed frames.
- The cursor layer is non-interactive and shares the same letterbox, zoom, and pan transform as the video.
- A black-and-white outlined pointer remains visible over both light documents and dark windows.
- The iPad system pointer preference remains separate; disabling it does not hide the remotely acknowledged Mac cursor.
